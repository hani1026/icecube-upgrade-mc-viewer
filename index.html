Event details

The sliders request an energy and direction. The closest stored event is loaded; its actual values appear in the status card. New event chooses another nearby recorded event. No MC event is generated or rescaled.

Solid paths use finite stored lengths or connect unambiguous parent–daughter vertices. A daughter position is its birth site, so a connecting path belongs to its parent. Coincident vertices stay coincident. Dashed long ν lines show direction, not a measured production point or flight length.

All native SplitInIcePulses remain unchanged. PMTs on the same module are combined only for drawing; marker size represents charge. Colors span the 2nd–98th pulse-time percentiles. Dust is a schematic 2,000–2,100 m depth overlay. No extra attenuation or reconstruction is applied.

This is an unweighted, balanced MC gallery, not an event-rate distribution.
